# Papers, explained

Scrollytelling versions of Jake Stein's research papers, served with GitHub Pages.

- `index.html`: landing page listing all papers
- `<paper-slug>/index.html` + `story.js`: one folder per paper
- `lib/`: shared d3 and scrollama

To add a paper: copy `uber-pay/`, rewrite the step cards in `index.html`, adjust the scenes in `story.js`, and add a card to the root `index.html`.
